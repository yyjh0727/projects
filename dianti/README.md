# 单电梯 LOOK 调度系统

C 语言实现的单电梯 LOOK 调度算法模拟。

## 设计

- 结构体封装电梯状态：当前楼层、运行方向（上行/下行/空闲三态枚举）、20 层请求位图
- LOOK 调度：沿当前方向服务沿途请求，该方向无请求时转向最近的反向请求，避免 SCAN 算法到顶/到底的无效移动
- 请求合法性校验：越界楼层与当前层过滤
- 模块化分层：init / add / find / set_dir / move / run

## 编译运行

```bash
gcc -o m main.c
./m
```

程序内置两轮乱序请求序列（8,3,12,5,15,2,10 与 6,18,1,9），运行后输出完整调度日志。
